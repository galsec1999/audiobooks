# Audiobooks

אתר One Page כללי בנושאי ספרי שמע, המתפרסם אוטומטית באמצעות GitHub Pages ונועד לגישה בקישור ישיר בלבד. הקטלוג כולל Self-Help, מדע בדיוני ומתח, תצוגת סדרות ומעטפת PWA להתקנה.

- אתר: https://galsec1999.github.io/audiobooks/
- מאגר: https://github.com/galsec1999/audiobooks
- דף הבית במקור: `index.html`

## עבודה מקומית

נדרשת Node.js גרסה 20 ומעלה.

```powershell
node tools/validate-site.mjs
node tools/build-site.mjs
```

לאחר הבנייה אפשר לפתוח את `_site/index.html` או להגיש את `_site` באמצעות שרת HTTP מקומי.

עדכון תקצירי המו״לים המאומתים:

```powershell
node tools/fetch-publisher-summaries.mjs
```

תרגום מקומי של תמציות המו״ל לעברית מתבצע באמצעות `tools/translate-summaries-he.py`; תוצרי התרגום נשמרים ב־`data/hebrew-summary-translations.json` ומוטמעים באתר בלי שירות תרגום בזמן גלישה.

## הוספת דף HTML

1. עורכים את `index.html` או מוסיפים קובץ `*.html` לשורש הפרויקט.
2. שומרים HTML מלא, UTF-8, עברית ו־RTL, title ו־viewport.
3. מריצים את שתי הפקודות שלעיל.
4. מבצעים commit ודוחפים ל־`main`.

דף הבית נשאר `index.html`. קטגוריות עתידיות יתווספו בתוך אותו דף/אתר, ללא יצירת אתר נפרד.

## ז׳אנרים, נושאים ומשאבי העמקה

- `genre` הוא ז׳אנר ראשי, למשל Self-Help, מתח או מדע בדיוני.
- `topic` הוא נושא פנימי בתוך הז׳אנר. השדה הישן `category` משמש מקור תאימות ל־`topic` עבור 185 רשומות המקור; 414 הרשומות המיובאות כוללות גם `genre` וגם `topic` מפורשים.
- `resources` הוא מערך של קישורים ישירים ומאומתים לתקציר או להעמקה.
- `AI ועסקים` הוא נושא פנימי אוצר בתוך Self-Help, עבור אסטרטגיית AI, מנהיגות, עבודה, יזמות וכלכלת טכנולוגיה.
- במובייל אזור החיפוש והמסננים מוצג כמגירה סגורה כברירת מחדל.
- לכל 926 הספרים יש תקציר בעברית; 741 תמציות רשמיות נמשכות מנתוני המוצר של Audible/המו״ל, מוגבלות ל־70 מילים, מתורגמות מקומית ומסומנות במקור ובתאריך אימות.
- מעבר “תצוגה: סדרות” מקבץ ספרים לפי פרטי הסדרה המאומתים ומציג את הספרים לפי מספרם בסדרה.
- קישורי Spotify, Google Play Books, Kobo ו־Libro.fm הם חיפושים בלבד; הזמינות והמהדורה אינן נחשבות מאומתות. Apple Books אינו נכלל.

## התקנת האתר

הבנייה כוללת `manifest.webmanifest`, ‏Service Worker ואייקונים מקומיים. בדפדפן תומך אפשר ללחוץ “התקנת האתר”; ב־Safari ב־iPhone/iPad משתמשים בשיתוף ואז “הוסף למסך הבית”. המטמון כולל רק את מעטפת האתר מאותו origin ואינו כולל analytics או trackers.

משאב חייב לכלול סוג, כותרת, מקור, URL מסוג HTTPS, סטטוס `verified: true` ותאריך `verified_at`. סרטון YouTube חייב לכלול משך של 1,200 שניות לפחות ואסור להפנות ל־Shorts. אם אין משאב מאומת, הכרטיס מציג מצב חסר ולא קישור חיפוש.

## מיון ונתוני Audible

האתר תומך במיון לפי חדש ביותר, ציון Audible, מספר דירוגי Audible, שם ומחבר. הממשק מציג את כמות הספרים שעבורם הנתון הנבחר זמין, וספרים ללא נתון מופיעים בסוף. מיון מכירות אינו מוצג משום שערכי `sales` הקיימים חלקיים ואינם נתוני מכירות Audible. הוא יופעל רק לאחר כיסוי מלא ומאומת של הקטלוג.

כל דף חייב לכלול `noindex,nofollow`. אין להוסיף analytics, trackers או sitemap. קובץ `robots.txt` חוסם סורקים, אך אינו מונע מאדם שקיבל את הקישור לפתוח או לשתף אותו.

## יבוא קטלוג

ספר מועמד מתווסף רק לאחר התאמת כותרת ומחבר ל־ASIN רשמי ואימות שהוא מוצר Audible שניתן להאזנה. אין להשלים קישור, קריין, תאריך, תקציר, דירוגים או מכירות באמצעות ניחוש. תוצאת היבוא האחרון מתועדת ב־`IMPORT_REPORT.md`.
